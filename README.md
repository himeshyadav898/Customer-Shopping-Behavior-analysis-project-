# 🛍️ Customer Shopping Behavior Analysis

## 📌 Project Overview

This project analyzes customer shopping behavior to identify purchasing patterns, sales trends, customer segments, category performance, subscription behavior, and customer satisfaction.

The project follows an end-to-end data analytics workflow using **Python, Pandas, SQL, and Power BI**.

The raw customer shopping data was cleaned and explored using Python and Pandas, analyzed using SQL to answer business questions, and finally visualized through an interactive Power BI dashboard.

---


## 🎯 Business Problem

Understanding customer shopping behavior helps businesses improve marketing strategies, customer retention, product performance, and overall sales.

This project aims to answer key business questions such as:

- Which product categories generate the most revenue?
- Which categories have the highest number of sales?
- Which age groups generate the most revenue?
- Which age groups make the most purchases?
- What percentage of customers are subscribed?
- What is the average customer purchase amount?
- What is the average customer review rating?
- Which customer segments should the business target?

---

## 🎯 Project Objectives

- Analyze customer purchasing behavior.
- Identify high-performing product categories.
- Analyze revenue and sales by category.
- Compare customer behavior across age groups.
- Analyze customer subscription status.
- Measure average purchase value.
- Analyze customer review ratings.
- Create an interactive Power BI dashboard.
- Generate actionable business recommendations.
